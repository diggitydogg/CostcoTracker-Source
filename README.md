# CostcoTracker SideStore Source

This repository hosts public SideStore releases of **CostcoTracker**, an independent iOS app for tracking Costco purchases, price changes, potential price matches, returns, receipts, and item purchase history.

> **CostcoTracker is not affiliated with, endorsed by, or sponsored by Costco Wholesale Corporation.**

## Install with SideStore

Add this source URL to SideStore:

```text
https://raw.githubusercontent.com/diggitydogg/CostcoTracker-Source/main/source.json
```

After adding the source, CostcoTracker can be installed and updated from SideStore.

## What this repository contains

This public repository is only for distribution.

It contains:

```text
README.md
icon.png
source.json
```

GitHub Releases contain:

```text
CostcoTracker.ipa
```

The application source code is maintained separately and is not currently open source.

## About CostcoTracker

CostcoTracker includes features such as:

- Costco warehouse and online purchase history;
- item purchase analytics and price history;
- potential price-match tracking;
- recorded price-adjustment history;
- saved returns and receipt information;
- warehouse receipt barcode display;
- local backup and restore.

## Releases

New builds are published automatically from the private development repository.

Each release includes a prebuilt unsigned IPA that SideStore signs for the user's device during installation.

Older releases may remain available for version history.

## Usage

Prebuilt IPA releases are provided for personal use by anyone who would like to install the app.

The app is provided **as-is**, without warranty or guarantee of continued support, compatibility, or availability.

## Privacy

CostcoTracker stores purchase and app data locally on the user's device.

Backup files may contain purchase and receipt history, so users should store them securely.

Costco authentication cookies and web-session credentials are intentionally excluded from CostcoTracker backup files.
